Source report audited: `illustrator-figma-feedback-2026-09.md`. Today: 2026-09-28.

## Notes

- **Figma's #1 forum request (file tags/folders) is now partly shipped** (2026 nested folders) — this kills a lot of the original report's "file format lock-in"/organization framing; the live gap narrowed to tagging/multi-classification and Drafts specifically.
- **Dev Mode pricing moved the opposite direction from what the source report claimed** — it got cheaper/bundled in 2026, not pricier. Any Omastrator pricing-positioning argument built on "Figma keeps adding paid tiers" should drop this example.
- **Figma's Organization price point is $55/editor/mo, not $75** — worth correcting anywhere this number appears in Omastrator's competitive materials.
- **The Figma AI-training lawsuit (Khan v. Figma) is real and ongoing**, but Figma already won arbitration on the named plaintiff's claims — so it's weaker ammunition for a "Figma is legally exposed" narrative than the original report implies; frame it instead as a trust/optics issue, which is still valid (default opt-in is a real, documented fact from Aug 2024).
- **Both companies' single highest-voted unbuilt items are performance/scale-adjacent**, not feature gaps: Figma's biggest unresolved ask (tags) and Illustrator's biggest (canvas size limit, 1,029 votes) are both about handling more/bigger work, not new creative capabilities — useful signal for Omastrator's own performance claims.
- **Real-time co-editing is a genuine Figma-over-Illustrator advantage** that Illustrator users actively request (multiple independent threads) and Adobe hasn't built — a concrete place a hybrid tool can credibly claim "best of both."
- **Vote counts on both platforms are much lower than the original report's rhetoric implied** — Figma forum "likes" mostly run in the single-to-low-double digits even for real, multi-year-old requests (except the 356-vote folders thread); Illustrator's UserVoice numbers run higher (100s–1,000+) and are a more reliable relative-demand signal. Treat any Figma forum "vote count" as an undercount of actual sentiment, since Discourse like-counts undercount silent agreement more than UserVoice's more prominent vote button does.
- **Reddit could not be directly crawled** (site is blocked to the web-search/fetch tools used here); all community-forum evidence above comes from Figma's own Discourse forum and Adobe's UserVoice/Community boards, which are the two platforms' actual "vote on a feature" venues anyway and are more authoritative for ranking demand than scattered Reddit threads would be.
- **Two citations in the source report were outright fabricated** (both Hacker News item IDs pointed to real-but-unrelated threads; one Adobe Community link pointed to a random 2009 Captivate thread) — any reuse of that report's "evidence" links should be re-verified individually before citing further.
